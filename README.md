# 에스텍 용역인력 견적시스템

에스텍베스트 동부지사의 경비·미화·주차·시설관리 용역 도급비 견적 프로그램입니다. 브라우저에서 바로 실행되는 단일 HTML 파일(`index.html`)로 동작합니다.

## 실행

`index.html`을 내려받아 PC 브라우저(Chrome·Edge)로 열면 됩니다. 별도 설치는 필요 없습니다.
인터넷에 연결되어 있으면 일반 지도(Esri)와 전국 사업장 검색(카카오맵 또는 OpenStreetMap)이 함께 동작합니다.

## 주요 기능

- **홈 화면**: 가운데 S-Tec 브랜드 영상(가로 꽉 차게), 에스텍그룹 홍보(주요 수치·사업 분야·연혁·사회공헌·그룹사·브랜드 이미지). 왼쪽에 신규 영업 견적·갱신 견적 버튼, 상단 파란 막대에 견적 담당·앱 다운로드 QR, 오른쪽에 사업 분야. 견적 화면용 메뉴·월 견적금액은 홈에서 숨김. 어느 화면에서든 왼쪽 위 로고를 누르면 홈으로 돌아옵니다.

| 단계 | 내용 |
|---|---|
| 1. 사업장·기본정보 | 신규 영업 견적(당해년·익년도 선택), 신규 영업 사업장 전국 검색(카카오맵 API 키 연결 시 카카오맵 기준), 기존 에스텍 사업장 151곳 현황, 관할 지사 거리, 인근 사업장 |
| 2. 인력 구성 | 직종(보안·미화·주차·시설·특수·기타)별 직책, 근무형태(주간 8~12h·3조2교대·4조2교대·5조2교대·격일제 등), 수당·상여금 |
| 3. 부대비용 | 업무차량(화물·세단·SUV·픽업·승합·전동카트), 미화·보안 장비, 기타 부대비용 카탈로그(통신·보호구·보험·소모품·법정 청소·교육 등, 인원 연동) — 인당 배분 또는 별도 청구 |
| 4. 요율·기준 | 연도별 최저시급·4대보험 법정요율(2025~2028), 일반관리비·이윤, 공급자·담당자 정보 |
| 5. 견적서 출력 | 견적서·산출내역서·부대비용·전년 대비 비교표 화면, 엑셀 내보내기 |

- **갱신 견적**: 당해년 견적을 불러와(지금 화면 · 이 기기 저장 · 파일(PC·태블릿·휴대폰) · Google Drive) 다음 연도 최저시급·요율로 다시 산출하고, 전년 단가와 비교표를 자동으로 만듭니다. 네이버 MYBOX는 공개 API가 없어 동기화 폴더·파일 선택 창으로 불러옵니다.
- **다른 양식 견적서 분석**: 지금 쓰고 있는 기존 견적서·산출내역서 엑셀(xlsx·xls·csv)을 불러오면 행 이름(기본급·인원·시급·시간외·심야·수당·단가·보험요율 등)과 열 머리글(직책·근무형태·연도)을 읽어 견적으로 바꿉니다. 원본 단가가 전년 단가가 되고, 직책별 조정수당을 자동 보정해 당해년 재계산 단가를 원본에 맞춥니다. 요약 견적서(인원·단가 표)만 있는 파일도 읽습니다.
- **고객사 양식 시트**: 다른 양식 견적서로 갱신 견적을 만들면 엑셀에 8번 시트(당해년 원본 견적서 그대로)와 9번 시트(같은 양식의 익년도 견적서)가 추가됩니다. 9번 시트의 시급·인원은 `산출내역서(익년)` 시트와 수식으로 연결되고, 보험요율은 익년도 요율로 바뀌어 고객사 원래 수식대로 다시 계산됩니다. 두 시트 아래에는 에스텍 산출내역서 단가와의 대조표(자동 연동)가 붙습니다. 구형 .xls 원본도 글꼴·색·테두리·병합·열 너비·그림·인쇄 설정까지 그대로 옮깁니다. 원본 파일은 이 기기 브라우저(IndexedDB)에 보관되며, 내보낸 엑셀을 다음 해에 다시 불러오면 9번 시트가 새 당해년 원본이 됩니다.
- **엑셀 내보내기**: 표지, 견적서, 산출내역서(모든 금액이 수식으로 연결), 전년대비 비교표, 당해년 견적, 부대비용 시트를 만듭니다. 숨김 시트에 견적 데이터가 함께 저장되어, 이 엑셀 파일만으로 다음 해 갱신 견적을 불러올 수 있습니다.
- **저장**: 견적은 브라우저(localStorage)에 저장되며 JSON으로 백업·불러오기가 가능합니다.

## 소스 구조

```
index.html            빌드된 단독 실행 파일 (웹 주소용)
에스텍_용역인력_견적시스템_v3.5.html  같은 파일 (PC 내려받기용)
manifest.webmanifest, sw.js, icon-*.png  휴대폰 앱 설치(PWA)용
src/app.html          화면·계산 엔진·엑셀 생성 코드 (템플릿)
src/leaflet.css       지도 스타일
assets/img.json       로고·직종 그림·담당자 사진·브랜드 이미지 (base64)
assets/intro.mp4      홈 화면 브랜드 영상 (빌드 시 파일 안에 포함)
assets/sites.json     에스텍 사업장·지사 위치 데이터
assets/adm.json       시·도/시·군·구/읍·면·동 경계 데이터
vendor/               Leaflet 1.9.4, ExcelJS 4.4.0, qrcode-generator 1.4.4, SheetJS 0.18.5 core (Apache-2.0·MIT)
tools/build.py        src + assets + vendor → index.html
```

수정 후 다시 만들기:

```
python3 tools/build.py
```

## 참고

- 2027년 장기요양·산재·임금채권·석면 요율과 고용보험 실업급여 인상분은 고시 전 잠정값입니다. 고시되면 요율·기준 화면에서 수정하세요.
- Google Drive 불러오기는 웹 주소(https)에서만 되며, Google Cloud에서 만든 OAuth 클라이언트 ID(웹, 승인된 원본에 `https://sadness500-boop.github.io`)를 갱신 견적 창의 ‘연결 설정’에 넣어야 합니다. 권한은 읽기 전용입니다.
- **카카오맵 자동 연결**: 저장소의 `app-config.json`에 카카오 디벨로퍼스 **JavaScript 키**(`kakaoJsKey`)를 넣으면 웹 주소로 접속한 모든 직원의 사업장 검색이 카카오맵으로 자동 연결됩니다. 카카오 앱 설정에서 ‘카카오맵’ 사용을 켜고, 플랫폼 ‘Web’에 `https://sadness500-boop.github.io`를 등록하세요. JavaScript 키는 등록한 주소에서만 동작합니다. PC에 내려받은 HTML 파일은 화면의 ‘카카오맵 연결’에 REST API 키를 넣어 씁니다. 키가 없거나 연결에 실패하면 OpenStreetMap으로 검색하고, 검색 목록 아래 카카오맵·네이버지도 바로가기를 보여 줍니다.
- 네이버지도는 장소 검색 API가 브라우저 직접 호출을 허용하지 않아, 같은 검색어로 네이버지도를 여는 바로가기로 제공합니다.

## 휴대폰 앱으로 쓰기

1. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/(root)`로 저장합니다(최초 1회).
2. 몇 분 뒤 `https://sadness500-boop.github.io/Quotation-System/` 주소가 열립니다. 메인 화면 오른쪽 **앱 다운로드 QR**이 이 주소를 가리킵니다.
3. 휴대폰 카메라로 QR을 찍어 연 뒤 브라우저 메뉴의 **홈 화면에 추가**(아이폰 Safari: 공유 → 홈 화면에 추가)를 누르면 앱처럼 설치됩니다.
