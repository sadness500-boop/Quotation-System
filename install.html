안드로이드 앱 설치

삼성 갤럭시 등 안드로이드 휴대폰·태블릿용 앱입니다. 인터넷 없이도 견적을 만들 수 있습니다.

⬇ 앱 내려받기 (APK)
  1. 위 초록 버튼을 누르세요“파일을 다운로드할까요?”가 나오면 다운로드를 누릅니다.
  2. 다 받아지면 열기를 누르세요알림창을 내려 ‘S-Tec-Quotation-System.apk’를 눌러도 됩니다.
  3. “출처를 알 수 없는 앱” 안내가 나오면설정 → 이 출처 허용을 켜고 뒤로 돌아오세요. 처음 한 번만 합니다.
  4. 설치를 누르세요“Play 프로텍트” 경고가 나오면 세부정보 더보기 → 무시하고 설치를 누릅니다. 사내용 앱이라 구글 스토어를 거치지 않아 나오는 안내입니다.
  5. 설치가 끝나면 열기홈 화면에 ‘S-Tec-Quotation-System’ 아이콘이 생깁니다.
새 버전이 나오면 이 페이지에서 같은 방법으로 다시 내려받아 설치하세요. 기존 앱 위에 덮어 설치되고, 저장한 견적은 그대로 남습니다. 만약 “앱이 설치되지 않았습니다”가 나오면 먼저 앱 안 ‘JSON 백업’으로 견적을 저장한 뒤, 기존 앱을 지우고 설치하세요.

아이폰 · 아이패드 — 홈 화면에 앱으로 추가

아이폰은 애플 앱스토어를 거치지 않은 앱 파일을 설치할 수 없어서, 사파리(Safari)로 열어 홈 화면에 추가합니다. 추가하면 아이콘을 눌러 앱처럼 전체 화면으로 열리고, 인터넷 없이도 열립니다.

견적시스템 열기
  1. 이 페이지를 사파리(Safari)로 여세요카카오톡·네이버 앱 안에서 열었다면 오른쪽 아래(또는 위) 메뉴에서 Safari로 열기를 누릅니다.
  2. 파란 견적시스템 열기 버튼을 누르세요견적시스템 화면이 열립니다.
  3. 화면 아래 공유 버튼을 누르세요네모에 위쪽 화살표가 있는 버튼입니다. 아이패드는 화면 위쪽에 있습니다.
  4. 목록을 위로 밀어 홈 화면에 추가를 누르세요안 보이면 맨 아래 작업 편집에서 추가할 수 있습니다.
  5. 오른쪽 위 추가를 누르면 끝홈 화면에 ‘에스텍 견적’ 아이콘이 생깁니다.
새 버전은 인터넷이 연결된 상태에서 앱을 열면 자동으로 바뀝니다. 따로 다시 설치할 필요가 없습니다.

PC에서 쓰기

크롬·엣지 브라우저로 바로 열어 쓰거나, 파일을 내려받아 인터넷 없이 쓸 수 있습니다.

견적시스템 열기
  1. 앱처럼 설치하기 (크롬·엣지)견적시스템을 연 뒤 주소창 오른쪽의 ⊕ 설치 아이콘을 누르면 바탕화면 아이콘이 생깁니다.
  2. 파일로 내려받기PC용 파일 받기를 눌러 저장한 뒤 더블클릭해서 엽니다.
